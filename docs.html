Документация CDNVideoHub

Универсальный баланcер принимает URL VK / YouTube / RuTube и формирует единую ссылку на плеер.

Быстрый старт

<script src="https://your-domain/script.js"></script>
<script>
const video = window.CDNVideoHub.detectVideo('https://youtube.com/watch?v=dQw4w9WgXcQ');
const embed = window.CDNVideoHub.buildUniversalEmbed('https://cdnvideohub.vercel.app', video);
console.log(embed);
</script>

Формат ссылки

https://your-domain/iframes/player?provider=youtube&id=VIDEO_ID&src=VIDEO_URL

Поддерживаемые провайдеры

  • VK: vk.com/video-1_2
  • YouTube: youtube.com/watch?v=..., youtu.be/..., youtube.ru/watch?v=...
  • RuTube: rutube.ru/video/...
